# Подключение

## Питание и шины

MPU6050 и магнитометр — оба на I2C1 (~100 кГц, standard mode; датчики
поддерживают до 400 кГц):

| STM32F303 | MPU6050 (GY-521) | QMC5883L (GY-271) | Примечание |
|---|---|---|---|
| PA15 (I2C1_SCL) | SCL | SCL | подтяжки 4.7 кОм к 3.3 В (обычно уже на модулях) |
| PB7 (I2C1_SDA) | SDA | SDA | |
| 3.3V | VCC | VCC | |
| GND | GND | GND | |
| GND | AD0 | — | адрес MPU 0x68 |

Адреса: MPU6050 `0x68`, магнитометр `0x0D` (QMC5883L/HA5883) или `0x1E`
(HMC5883L) — драйвер определяет автоматически. Если AD0 притянут к VCC —
поменяйте `IMU_MPU6050_ADDR7` на `0x69` в `imu_config.h`.

## Про чип магнитометра

Модули GY-271/GY-273 бывают на двух НЕ совместимых по регистрам чипах:

- **QMC5883L** (QST) — на модулях часто маркирован `HA5883`, `DB5883` или
  `QMC5883L` (вторая строка маркировки, например `5035` — код партии/даты).
  I2C-адрес `0x0D`, частота до 200 Гц.
- **HMC5883L** (Honeywell) — классический GY-271. I2C-адрес `0x1E`,
  частота до 75 Гц.

Прошивка ищет датчик сначала на `0x0D`, затем на `0x1E`; обнаруженный
вариант печатается на отладочную консоль (USART1) при старте:
`MAG: QMC5883L/HA5883 @0x0D OK` или `MAG: HMC5883L @0x1E OK`.

## Про чип MPU6050

Оригинальные MPU6050 сняты с производства, модули GY-521/GY-271 теперь
поставляются с клонами (чаще всего **MPU6500**). Разница — только
`WHO_AM_I`: оригинал отвечает `0x68`, MPU6500/клоны — `0x70`. Карта
регистров (данные, масштабы, DLPF) совместима, поэтому прошивка принимает
оба ID и печатает найденный при старте:
`MPU: OK, WHO_AM_I 0x68 (MPU6050)` или `MPU: OK, WHO_AM_I 0x70 (MPU6500/клон)`.

Если после прошивки данные акселерометра в покое — мусор (дёргается, нули,
гигантские значения) — чип несовместимый, модуль придётся заменить.
Стабильное отклонение до ~10% (например Z = 10.6 м/с² в покое вместо 9.81) —
типично для клонов: общий коэффициент масштаба сокращается в отношениях,
так что на ориентацию (кватернион, азимут) он не влияет.

## UART к роботу (ROS 2)

USART2, 115200 8N1, бинарный протокол:

| STM32F303 | Робот / USB-UART |
|---|---|
| PA2 (USART2_TX) | RX |
| PA3 (USART2_RX) | TX |
| GND | GND |

Уровни 3.3 В! Для Raspberry Pi подключайте напрямую к GPIO UART
(TX↔RX крест-накрест). Для ПК используйте USB-UART адаптер 3.3 В.

Для проверки с ПК есть готовое тестовое приложение
(`tools/windows_imu_viewer`, запуск `run.bat`) — показывает азимут,
кватернион и сенсоры и позволяет запускать калибровки.

Важно: скорость USART2 (115200) задана в `MX_USART2_UART_Init()` вне
USER CODE-секций. При перегенерации кода из CubeMX (.ioc) выставьте
115200 в настройках USART2 вручную, иначе вернётся старое значение.

## Отладочная консоль

USART1, 9600 8N1, текст:

| STM32F303 | USB-UART |
|---|---|
| PC4 (USART1_TX) | RX |
| PC5 (USART1_RX) | TX |
| GND | GND |

При старте плата печатает версию и **блок диагностики**, каждые 10 с —
статусную строку. Это основной инструмент отладки «что не работает»:

```
=== IMU DIAG: BOOT ===
CLK: SYSCLK 72 MHz (HCLK /2, PCLK1 /1), I2C1 <- HSI 8 MHz
I2C1 SCAN: 0x68=1 0x69=0 0x0D=1 0x1E=0      <- кто на шине I2C
MPU WHO_AM_I: 0x68 (ожидаем 0x68 при AD0=GND)
MAG@0x0D CHIP_ID: 0xff (ожидаем 0xff = QMC5883L/HA5883)
MPU data: a=(0.00 0.00 9.81) m/s2 ...       <- первое сырое чтение
MAG data: (20.0 0.0 -45.0) uT | QMC5883L/HA5883 @0x0d
=== IMU DIAG: BOOT END ===
ST t=10 s | MPU ok (err 0) MAG ok(QMC) (err 0)
  q=(0.71 0.00 0.00 0.71) rpy=(0.0 0.0 45.0) az=45.0 deg
  g=(...) a=(...) T=... C
  m=(...) uT 9x | 50 Hz frames=500 mpu_age=4 ms mag_age=8 ms send_age=6 ms
```

Как читать: `I2C1 SCAN` — на каком адресе кто ответил; `err` — счётчики
сбоев чтения; `mpu_age/mag_age` — давность последнего успешного чтения
(растёт — датчик «завис»); `send_age` — давность последней отправки по
USART2 (растёт — проблема с линией к роботу); `9x`/`6x` — фильтрация по 9/6 осям.

**Важно про PA15:** на STM32F3 он по умолчанию — JTAG (JTDI), но пин
освобождается автоматически, стоит запрограммировать его в альтернативную
функцию (RM0316, §33.4.4) — прошивка так и делает (`I2C1_SCL`, AF4). Вручную
«отключать JTAG» в прошивке не нужно (в отличие от STM32F1). SWD для
программирования (PA13/PA14) при этом продолжает работать.

**Если `I2C1 SCAN` показывает `0x68=0 0x0D=0`:** у STM32F3 нет встроенных
подтяжек на I2C — без внешних резисторов шина может не работать. Поставьте
4.7 кОм SCL→3.3V и SDA→3.3V (рядом с модулем) и проверьте: питание модулей
3.3V, общий GND, не перепутаны ли SCL/SDA.

## Монтаж

- Ось X платы — вперёд по ходу робота, Y — влево, Z — вверх.
- Если плата стоит иначе — задайте перестановку в `imu_config.h`
  (`IMU_MOUNT_*`) вместо переворачивания в ROS.
- Магнитометр боится железа и токов: держите моторы, динамики,
  силовые провода минимум в 10–15 см; калибруйте маг на собранном роботе.
- MPU6050 и QMC5883L должны быть жёстко закреплены относительно друг друга.
