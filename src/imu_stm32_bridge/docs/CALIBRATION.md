# Калибровка

## Что калибруется

1. **Дрейф гироскопа** — снимается автоматически при старте, если во flash
   нет сохранённой калибровки (плату не трогать ~2 с после включения).
   Вручную: команда `GYRO_CALIB` / сервис `~/gyro_calib`.
2. **Магнитометр (hard/soft-iron)** — обязательно на собранном роботе,
   рядом с моторами и проводами. Хранится во flash.
3. **Склонение** — по умолчанию +11.5° (Москва). Узнайте своё на
   magnetic-declination.com и задайте параметром `declination` или командой
   `SET_DECLINATION`, затем `SAVE_FLASH`.

4. **Гейн акселерометра** — не калибруется в текущей версии. У клонов MPU
   бывает отклонение до ~10% (пример: Z = 10.6 м/с² в покое вместо 9.81).
   На ориентацию/азимут не влияет (общий коэффициент сокращается в
   отношениях). Если понадобится точное линейное ускорение — нужна
   поосевая калибровка (отдельная задача).

## Калибровка магнитометра через ROS 2

```bash
ros2 service call /imu/imu_stm32_bridge/mag_calib_start std_srvs/srv/Trigger
# Медленно вращайте РОБОТА ЦЕЛИКОМ ~30 с:
# - полный оборот вокруг вертикальной оси,
# - наклоны вперёд/назад и влево/вправо,
# - переверните вверх ногами, если возможно.
# Прогресс (%) виден в логе узла (сообщения CALIB).
ros2 service call /imu/imu_stm32_bridge/mag_calib_stop_save std_srvs/srv/Trigger
```

Проверка: поле `status` в `/imu/data`... точнее бит `MAG_CAL` в статусе
кадра (виден в логе узла), азимут при повороте на 360° должен проходить
0..360 монотонно без скачков.

Отмена без применения: `mag_calib_cancel`.

## Проверка качества

- Положите робота на стол, покрутите на 90° — азимут должен меняться
  примерно на 90° (сверьтесь с телефонным компасом с учётом склонения).
- Наклоните робота на 20–30° без поворота — азимут должен стоять
  (компенсация наклона работает).
- В логе узла режим должен быть `9x`. Режим `6x` означает проблемы с магом
  (обрыв, переполнение рядом с железом) — курс будет дрейфовать.

## Сброс

- Снять обнуление курса: сервис `~/clear_yaw`.
- Перезаписать калибровки: выполните калибровки заново и `~/save_flash`.
- Полный сброс flash: залейте прошивку с массовым стиранием
  (STM32CubeProgrammer, Full chip erase) — при старте загрузятся defaults.
